# PDF → Excel: Конвертер спецификаций

Извлекает спецификации оборудования, изделий и материалов из чертежей ГОСТ (PDF из AutoCAD)
с помощью **Google Gemini** и собирает их в оформленную Excel-таблицу.

Для каждого PDF создаётся отдельный лист, плюс общий сводный лист со всеми позициями.

Проект можно использовать двумя способами:

- **CLI** — сложить PDF в папку и запустить скрипт (`./run.sh`);
- **Веб-приложение** — бэкенд на FastAPI + фронтенд на React/TypeScript с drag-and-drop.

Общая логика разбора и генерации Excel живёт в `converter_core.py` — её используют оба способа.

```
converter/
├── convert.py            CLI-обёртка
├── converter_core.py     общая логика (PDF → Gemini → Excel)
├── run.sh                запуск CLI
├── backend/              FastAPI API
│   ├── main.py           эндпоинты /api/convert, /api/export, /api/health
│   ├── requirements.txt
│   └── run_api.sh        запуск API
└── frontend/             React + TypeScript + Vite + Tailwind
    └── src/              drag-and-drop, таблица результатов, скачивание Excel
```

---

## Веб-приложение (рекомендуется)

Нужны **два терминала** — один под API, один под фронтенд.

**Терминал 1 — бэкенд** (порт 8000):

```bash
./backend/run_api.sh
```

**Терминал 2 — фронтенд** (порт 5173):

```bash
cd frontend
npm install     # только при первом запуске
npm run dev
```

Откройте <http://localhost:5173>, перетащите PDF-чертежи, дождитесь разбора,
проверьте таблицу и нажмите **«Скачать Excel»**.

> Фронтенд в dev-режиме проксирует запросы `/api/*` на бэкенд (порт 8000),
> поэтому настраивать адреса и CORS вручную не нужно.

## CLI

### Быстрый старт

1. Положите PDF-файлы в папку `input_pdfs/`.
2. Запустите:

   ```bash
   ./run.sh
   ```

3. Результат появится в файле `Сводная_Спецификация_MVP.xlsx`.

Активировать виртуальное окружение (`source venv/bin/activate`) **не нужно** —
скрипт `run.sh` сам использует Python из `venv`. Если папки `venv` нет,
скрипт создаст её и установит зависимости автоматически.

---

## Настройка API-ключа

1. Получите ключ на <https://aistudio.google.com/apikey>.
2. Скопируйте шаблон и вставьте свой ключ:

   ```bash
   cp .env.example .env
   ```

   Затем откройте `.env` и замените значение:

   ```
   GEMINI_API_KEY=ваш_ключ
   ```

Файл `.env` не попадает в git (защищён `.gitignore`), поэтому ключ не утечёт.

## Способы запуска

| Способ | Команда | Активация venv |
|--------|---------|----------------|
| **Рекомендуемый** | `./run.sh` | не нужна |
| Напрямую | `./venv/bin/python3 convert.py` | не нужна |
| Классический | `source venv/bin/activate` → `python3 convert.py` | нужна |

## Выбор модели Gemini

По умолчанию используется `gemini-3.6-flash`. Модель можно переопределить
через переменную окружения, не меняя код:

```bash
GEMINI_MODEL=gemini-3.5-flash ./run.sh
```

При временной перегрузке модели (ошибки `429`/`503`) скрипт автоматически
повторяет запрос с нарастающей задержкой.

## Зависимости

- `pandas` — сборка таблиц
- `pypdf` — чтение текста из PDF
- `python-dotenv` — загрузка ключа из `.env`
- `google-genai` — обращение к Gemini API
- `openpyxl` — запись и форматирование Excel

Все они устанавливаются автоматически при первом запуске `./run.sh`.

> **Примечание.** Конвертер работает с векторными (цифровыми) PDF, где есть
> текстовый слой. Отсканированные картинки без текста обработать не получится.

## Деплой и обновление на сервере

Сервер привязан к этому репозиторию (read-only deploy key). Сервис слушает
`127.0.0.1:8137`, наружу отдаётся через Cloudflare Tunnel → nginx на `spec.biy.kz`.

**Первая установка** (уже сделана): `bash setup_server.sh` → `.env` с ключом → `bash start.sh`.

**Любое обновление** — одна команда на сервере:

```bash
cd ~/converter && git pull && bash start.sh
```

Автозапуск после перезагрузки настроен через `crontab @reboot`.
Разработка ведётся локально: правки → `git push` → на сервере `git pull`.
